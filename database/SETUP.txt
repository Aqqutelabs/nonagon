NONAGON LOCAL DATABASE SETUP

1. Start Apache and MySQL in XAMPP.
2. Copy .env.example to .env and update the database credentials if needed.
3. Import database/schema.sql through phpMyAdmin or the MySQL client.
4. Open http://localhost/nonagon/register.php.

In APP_ENV=local, failed email delivery exposes the verification or invitation
link on the relevant page so the complete flow can be tested without a mail
server. Configure production mail delivery before deployment.
